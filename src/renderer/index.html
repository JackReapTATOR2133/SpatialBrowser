🧩 Розширення

WebExtensions: Firefox (.xpi), Chrome (.crx), .zip або розпакована папка
Перетягніть сюди файл .xpi, .crx або .zip
Розширення працюють у всіх просторових вікнах. Підтримується підмножина WebExtensions API, яку надає Electron: content scripts, storage, runtime, tabs, webRequest. Деякі складні аддони можуть працювати частково.
