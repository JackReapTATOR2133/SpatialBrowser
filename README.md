# Spatial Browser — Phase 1: Architecture, Foundation & Core Interface

> **Spatial Browser** — це настільний браузер нового покоління, побудований навколо просторової організації вебконтенту замість традиційної системи горизонтальних вкладок. Кожна відкрита вебсторінка є окремим незалежним плаваючим вікном, яке користувач може вільно переміщувати, масштабувати та накладати одне на одне в межах спільного робочого простору.

---

## 🛠 Технологічний стек

- **Electron 36.9.5** — сучасна десктопна платформа
- **Chromium** — браузерний рушій
- **WebContentsView** — нативний шар для рендерингу незалежних вебсторінок
- **HTML5 / CSS3 / JavaScript (ES2024)** — інтерфейс користувача (Cyberpunk / Modern Dark UI)
- **Node.js** — системна логіка бекенду
- **JSON** — локальне сховище закладок та конфігурації (`data/bookmarks.json`)

## 🧩 Ключові компоненти інтерфейсу

### 1. Верхня панель навігації (Navigation Toolbar)
- **Адресний рядок**: розумне введення URL. Якщо введено валідний URL — здійснюється прямий перехід; якщо введено текст або пошуковий запит — автоматично відкривається пошук у Google.
- **Кнопка переходу (➜)**: застосовує введену адресу до поточного активного вікна або створює нове, якщо вікна відсутні.
- **Кнопка "+ Нове вікно"**: створює нове просторове вебвікно з каскадним зміщенням.
- **Кнопка "🏠 Home Hub"**: відкриває висувну стартову шторку Speed Dial.
- **Кнопка "🗂️ Вкладки" (Tab Manager)**: відкриває спливаюче меню відкритих вікон з бейджем кількості.

### 2. Spatial Workspace (Просторовий робочий простір)
- Займає всю доступну площу екрана під тулбаром.
- Кожне вебвікно візуалізується через **фантомну рамку (Phantom Frame)** у DOM і пов'язаний нативний **WebContentsView**.
- Вікна можна вільно переміщувати мишкою за заголовок (drag-and-drop).
- Зміна розміру підтримується у всіх **8 напрямках** (`n`, `s`, `e`, `w`, `ne`, `nw`, `se`, `sw`).
- Вікна можуть вільно перекриватися. Клік на вікно автоматично переносить його на передній план (`bringToFront`).
- Кожне вікно має власні кнопки навігації: **Назад (◂)**, **Вперед (▸)** та **Закрити (✕)**.
- Координати вікон обмежені робочою областю (**clamping**). При зміні розміру головного вікна позиції коректно адаптуються.

### 3. Home Hub — стартова сторінка із закладками (Speed Dial)
- Висувний стартовий екран у стилі Speed Dial (Opera GX).
- Візуальна сітка інтерактивних карток із фавіконами, назвами та URL.
- Повноцінний CRUD:
  - Додавання нових закладок через модальну форму.
  - Редагування існуючих закладок.
  - Видалення закладок.
  - Зміна порядку закладок (вгору/вниз).
- Клік по закладці миттєво відкриває відповідний сайт у Spatial Workspace.
- Вбудований рядок пошуку по закладках або в інтернеті.
- Дані зберігаються локально в `data/bookmarks.json` і зберігаються між сесіями.

### 4. Tab Manager — висувна ліва бічна панель відкритих вебвікон
- Відкривається через ліву кнопку меню `☰` у верхній панелі навігації.
- Висувається у вигляді ергономічної бічної панелі зліва (`Drawer Sidebar`) із напівпрозорим бекдропом.
- **Повноцінна система закривання**:
  - Велика виразна кнопка закриття `✕` у шапці бічної панелі.
  - Повторний клік на кнопку `☰` у тулбарі.
  - Клік у будь-яке місце робочої області (поза панеллю або по бекдропу).
  - Натискання клавіші `Escape`.
  - Автоматичне закриття після вибору потрібного вікна.
- Показує актуальний список усіх відкритих WebContentsView з фавіконами, назвами сторінок, URL та індикатором активного вікна.
- Дозволяє перемикатися на будь-яке вікно в один клік (вікно переноситься на передній план).
- Кнопка швидкого закриття окремого вікна `✕` на кожній картці.
- Вбудований рядок пошуку/фільтрації відкритих вкладок.
- Кнопка «Закрити всі» в нижній панелі.
- Автоматично оновлюється при створенні, закритті або навігації сторінок.

## ⚡ Архітектурний компроміс: Window Shelf та захист панелей керування

### Чому виникала проблема?
У Chromium/Electron нативний шар `WebContentsView` завжди рендериться поверх плоского HTML DOM. При накладенні одного просторового вікна на інше, нативне тіло верхнього вікна закривало DOM-заголовок нижнього вікна, позбавляючи користувача кнопок закриття та навігації.

### Реалізований компроміс:
1. **Чистий 1:1 рендеринг кожного вікна**:
   - Розміри та положення `WebContentsView` кожного вікна строго відповідають його фізичному контейнеру.
   - Жодне вікно не деформує, не зсуває і не ламає верстку інших сторінок.
2. **Window Shelf у верхній навігаційній панелі (Master Deck)**:
   - У верхній тулбар (який знаходиться вище робочої області на `y: 0..56` і фізично не може бути перекритий жодним вікном) інтегровано інтерактивну полицю вікон:
     - Кожне вікно представлене стильним чіпом із фавіконом, назвою та власною кнопкою `✕`.
     - Клік по чіпу миттєво піднімає вікно на самий передній план.
     - Клік по `✕` на чіпі миттєво закриває відповідне вікно в один клік — навіть якщо воно на 100% закрите іншими вікнами!
3. **Master Controls у тулбарі для активного вікна**:
   - Кнопки `◂` Назад, `▸` Вперед, `⟳` Оновити, та червона кнопка `✕` Закрити активне вікно.
   - Гаряча клавіша **`Ctrl+W`** для миттєвого закриття активного вікна з клавіатури.
4. **Висувна ліва панель Tab Manager (`☰`)**:
   - Повний огляд, пошук та кнопка «Закрити всі».
5. **Фізичні рамки вікон на столі**:
   - Заголовок кожного вікна працює для прямого перетягування мишкою, а клік по будь-якій видимій частині рамки миттєво робить вікно активним.

## 🔒 Архітектура безпеки Electron

- `nodeIntegration: false` — повна заборона Node.js у контексті рендерера
- `contextIsolation: true` — сувора ізоляція контекстів
- `sandbox: true` — увімкнений пісочничний режим
- `preload.js` — строго обмежений міст `contextBridge` без доступу до системних API
- Захищений список IPC-каналів без виконання довільного коду
- Вебконтент завантажується виключно в ізольованих WebContentsView
